On-device dictation: engines & what open source uses

A quick look at how open-source dictation apps do speech-to-text — model + CPU/GPU/NPU — plus a small hands-on benchmark of the engines relevant to Jot. Compiled 2026-07-23.

1. Benchmark — the engines that matter for us

Read this honestly. The clips are clean text-to-speech, which is optimistic and flattens accuracy differences — all three scored ~perfect. Real accented/noisy speech would separate the 600M models (Parakeet v3, Nemotron) from tiny Whisper-base. Both Parakeet and Whisper auto-convert numbers to digits (this made a spelled-out "twenty first" look like an error — it isn't). Nemotron was timed in batch mode, same as the others, so the speed comparison is fair — but note Jot actually runs Nemotron streaming for live captions. † Parakeet v3 here is offline; a streaming Parakeet exists via sherpa-onnx. Single run each on one CPU — treat as rough, not lab-grade.

Takeaway: on CPU, Parakeet v3 is ~7× faster than our Nemotron 3.5, smaller, just as accurate on this test, and CC-BY-4.0 (shippable). Nemotron's advantage is that we run it as a real streaming engine. A Parakeet-v3 move would want a streaming export (sherpa-onnx) to keep live captions.

Underlying engines: whisper.cpp (CPU, CUDA, Metal, Vulkan, CoreML→ANE, OpenVINO, Ascend) is the broadest; faster-whisper/CTranslate2 is CPU + NVIDIA-CUDA only (no AMD/Vulkan/NPU); sherpa-onnx runs Parakeet/Whisper/Zipformer on ONNX Runtime with CPU/CUDA/CoreML/DirectML + embedded NPUs (QNN, RKNN, Ascend); FluidAudio runs Parakeet on the Apple Neural Engine.

3. What we can learn

  • Parakeet v3 is the field's rising default (Handy, Whispering, VoiceInk, Vibe) — and our benchmark shows why: fastest on CPU, small, accurate, permissive license. Worth seriously considering as Jot's engine (with a streaming export to keep live captions).
  • On Windows, the field GPU-accelerates with Vulkan, not DirectML — and nobody GPU-accelerates Parakeet in shipping builds (Handy explicitly leaves it CPU-only). Jot's DirectML path is unusual; a Parakeet-on-GPU (or NPU) Jot would be ahead of the pack.
  • NPU is Apple-only in practice. VoiceInk/FluidAudio run Parakeet on the Apple Neural Engine. No shipping Windows dictation app uses the NPU (QNN/OpenVINO are library-level, experimental). If Jot shipped NPU, it'd be close to first.
  • Nemotron 3.5 is niche — only Vibe also ships it. Our benchmark suggests it's not obviously worth its size/speed cost over Parakeet v3 on CPU, unless its streaming quality is the deciding factor.
  • Ideas worth borrowing: one interface over two engines (whisper.cpp for Whisper + ONNX for Parakeet, à la transcribe-rs); model download with a manual mirror for firewall/corporate networks (Handy); and configurable paste method + clipboard fallback — Handy uses synthetic input (enigo) with paste_method/clipboard settings, i.e. they hit the same paste problem we did and solved it the same way.
Benchmark: onnx-asr (ONNX Runtime, CPU) for Parakeet v3 & Whisper; Jot's own engine for Nemotron; 3 TTS clips, warmed, single run. Sources: repos linked above, onnx-asr, sherpa-onnx, FluidAudio, whisper.cpp, Parakeet v3 (NVIDIA).
